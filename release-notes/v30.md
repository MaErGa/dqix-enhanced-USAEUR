DQIX Enhanced v30: widescreen without pop-in.

**What's new since v29**
- **Widescreen: no more pop-in at the sides.** People, doors, items and
  monsters near the left and right edges no longer vanish: the game asks
  the DS whether each one is in view, and in widescreen it now gets the
  answer for the whole wide picture. (Not while playing with friends far
  away: there every PC has to make exactly the same decisions.)

**How to install**: download *Source code (zip)* below, unzip it and
double-click `Install Dragon Quest IX.bat`. **Already on v29?** The game
offers the update when it starts (or Help > Check for updates): your saves
and settings are kept.

**Playing with friends**: everyone needs the same version, so all of you
update to v30.

The plans for what comes next are in ROADMAP.md.
