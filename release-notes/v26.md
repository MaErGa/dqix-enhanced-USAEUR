The first stable version of DQIX Enhanced: the whole of Dragon Quest IX,
built into a native Windows game from your own ROM.

**What's in it**
- **Classic mode**: every frame exactly as a DS draws it, with the DS's sound
  and timing.
- **Enhanced mode**: the 3D on your graphics card at up to 4x resolution
  (F5 switches at any time).
- **The DS Lite look**: screen filter (colours, pixel grid, motion blur,
  backlight levels) and the console around the screens, as a photo or drawn
  in six colours, even at actual size.
- Keyboard, mouse (as the touch screen) and gamepads; fast forward; every
  setting in the menu bar.
- **Sellma's downloads offline** through a built-in Wi-Fi server, including
  DQVC on its original calendar (with the optional extras in this version).
- Saves compatible with the DS; F10 bug reports.

**How to install**: download *Source code (zip)* below, unzip it, put your
ROM in the `rom` folder and double-click `BUILD.bat`. See the README for
details. Nothing from the game is included: the build makes it from your ROM.

This version doesn't update itself yet; the next stable (v27) will, and so
does the nightly.
